# Spendly — site

Landing page and privacy policy for the Spendly Android/iOS app,
served via GitHub Pages.

- Home: https://anupm-sinha.github.io/spendly-site/
- Privacy policy: https://anupm-sinha.github.io/spendly-site/privacy.html

The privacy policy URL is referenced from the app (Settings → Privacy
policy) and from the Google Play listing. **If it moves, update both** —
Play rejects listings whose policy link 404s.

App source: https://github.com/anupm-sinha/spendly-flutter (private)
